# 24 秒竖屏概念方案 · 待配歌校准

工作主题：为自己留下名字。9:16，24 秒。没有收到歌曲母版与准确歌词，下面按情绪分配秒数；实际踩点必须在音频到位后调整。1080×1920 是建议交付画布，生成分辨率以账号可选项为准；放大 720p 不会产生真实细节。

## 分镜

| 镜头 | 成片区间 | 画面与作用 | 素材策略 |
|---|---|---|---|
| M01 | 0–2 秒 | 红衣木兰直视镜头，风吹起红带；先让观众记住主角 | 补生成；低机位中近景，单次缓慢前推 |
| M02 | 2–5 秒 | 灰衣木兰读征书，手指停住；交代她的选择从何而来 | 优先取原片约 9–12 秒的无字原素材；没有则补生成 |
| M03 | 5–7 秒 | 父亲低头触碰旧盔甲；动机落地 | 优先原片约 19.5–22 秒；处理时间线 |
| M04 | 7–10 秒 | 木兰把红发带系紧；从被动转为主动 | 补生成；只拍一次完成的动作，手部难则改背面轮廓 |
| M05 | 10–14 秒 | 穿上红衣护甲的木兰踏出门，腰部细节接中景 | 补生成；通过硬切做换装，不依赖连续变装 |
| M06 | 14–18 秒 | 正对镜头的上半身演绎；短暂点头、肩部节奏、眼神坚定 | 补生成；没有配歌先闭口表演；有母版再测试约 3–4 秒口型 |
| M07 | 18–22 秒 | 低机位英雄中景，身后红旗，木兰一步站定 | 补生成；动作简洁，剑留在鞘中 |
| M08 | 22–24 秒 | 最有力量的近景停留，后期显示歌名和艺名 | 复用 M01 或 M07 的干净尾段，后期排字 |

先做 M01。它同时验证脸、红衣、镜头和态度，投入小、信息量大。M01 通过后再扩展，不同时提交整批。

## 即梦中的操作顺序

打开即梦网页的视频生成，选择账号界面显示的 Seedance 2.5。官方发布已列明该入口；具体按钮、上传数量、费用和功能仍以账号实际页面为准。[官方说明](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)

1. 选 9:16；先做单镜头短测试，页面可选约 4–6 秒时先选 5 秒。
2. 上传干净主脸与对应服装参考。当前两张拼图用于辅助理解；优先取得各视图原图，或在自己图像工具中裁成独立参考。
3. 在提示词中分别交代每个素材的用途。下文 `@图片1` 等是示意：使用页面真实的引用控件和名称绑定，不能只打字就假定图片已经绑定。
4. 粘贴单镜头提示词，检查积分和本次设置，提交一次。
5. 下载原始视频，检查开头、中间、末尾及连续运动；记录实际积分、生成次数和问题。

模型支持更长或更多参考，不代表每次应全部用满。以下分镜生成方法是可控性优先的制作建议，并非 Seedance 的硬性限制。

## 主参考的职责

- `@图片1`：同一张主脸；只负责五官、脸部比例、基础皮肤与身份。
- `@图片2`：当前镜头对应的全身服装与发型。
- `@图片3`：已有时上传镜头关键帧；负责构图、场景和光线。
- `@音频1`：用户选好的原曲片段；仅在需要音乐驱动或口型测试时上传。
- 视频参考：有授权素材时只指定学习运镜或动作，明确人物外形仍以自己的图为准。

## M01：第一条可直接测试的提示词

```text
生成一段 5 秒、9:16 竖屏的写实古装音乐宣传镜头，单一连续镜头。
成年花木兰的身份和五官以 @图片1 为准；红色旧布战袍、黑色皮甲、高马尾与红发带以 @图片2 为准。仅一个人物，不复刻参考图的拼图、边框、文字或小格。
她站在黎明军营的木门前，背景只有虚化的暗红旗帜与少量尘雾。从胸口以上的中近景开始，机位略低于眼睛，镜头缓慢前推到面部近景。
0–2 秒，她下颌略低，双眼抬起直视镜头；2–4 秒，她保持视线，轻轻抬起下颌，气质克制而坚定；4–5 秒保持动作完成后的姿态。只让发丝、红发带和衣角受同一方向的微风影响。
灰蓝环境光，柔和侧逆光，面部仍能看清。皮肤保留自然纹理，布料磨损和黑铁哑光质感清楚，暗红是主要强调色。
嘴唇自然闭合；保持脸部比例、服装结构和头发长度稳定。画面无字幕、无片名、无额外人物。不要新增台词或歌声。
```

如果没有独立主脸，先用整张图测试时需明确引用中央正面头像作为身份依据；它仍可能不如独立参考稳定。不要把参考中细节看不清的问题交给形容词解决。

## M04：系发带

```text
5 秒，9:16，写实电影质感，单镜头。成年花木兰身份以 @图片1 为准，灰色麻衣、盘发阶段以 @图片2 为准。镜头位于她背后肩膀上方，近景只拍后脑与双手。
她将一条暗红布带绕过扎好的头发，双手各握一端，缓慢拉紧一次，动作完成后停住。保持双手、布带和头发接触关系清楚，不切镜，不环绕，不同时变装。
清晨窗侧柔光，旧木屋暗背景，灰麻与暗红形成对比，皮肤和布料质感自然。无字幕、无文字、无台词。
```

手指或布带穿模时，下一版改为“背面近景，布带已系好，手松开离开画面”。只降低失败动作复杂度，不同时更换脸、服装与摄影风格。

## M05：迈出木门

```text
5 秒，9:16，单一写实镜头。成年花木兰的脸以 @图片1 为准，红衣黑甲、高马尾与红发带以 @图片2 为准。
她站在木门内，右手自然靠近腰间剑鞘但不拔剑。固定的低机位中景，她向镜头方向迈出一步，靴子落地，衣摆随后落下，身体稳定站住。背景木门与光线连续一致。
冷灰清晨，门外微弱暖色边缘光，黑铁和旧红布有真实重量。一个主要动作，摄影机不旋转，服装没有突然增减。无字幕、无片名、无台词。
```

## M06：歌手表演与口型

无歌曲母版时，先用闭口眼神和身体节奏建立角色。收到音频后才把这段改为口型测试：

```text
使用 @音频1 的指定短句作为表演参考，人物身份以 @图片1 为准，红衣黑甲以 @图片2 为准。正面胸像，头部小幅运动，嘴部不被手或头发遮挡，摄影机缓慢前推。
人物演唱的句子仅为：【填入这一小段的准确歌词】。按照参考音频的发音和节奏表演，表情克制、坚定，肩部轻微跟随音乐。保持原有人物音色和脸部，不新增其他人声或歌词。无字幕。
```

这是待验证的控制意图，不是保证无误的口型功能。最终声音仍使用用户原曲；若生成版改了音频、节奏或发音，静音生成音轨，重测短句或用叙事镜头覆盖，不把失同步段作为主镜头。

## 剪辑与验收

先在剪映或常用编辑器中放入原曲片段，标记开头、主重拍、换句、结尾，再对齐镜头。先切清楚动作和情绪，转场以硬切和动作接切为主。不要每个鼓点都切；允许人脸停留，让观众记住角色。

字幕在后期统一制作，9:16 用手机检查，避开平台底部按钮、右侧交互栏和人物脸。歌名、艺名尚未给定时，不把工作主题误当作正式发行标题。

每镜检查：脸是否同一设定，伤痕是否换边，护甲是否跳变，手指与道具是否穿插，动作是否有目的，眼神是否稳定，是否出现乱字，起落动作是否有剪辑余量。整片检查：首两秒是否有主角，红衣是否有记忆点，音乐切点是否自然，是否有黑尾或截断人声。
