# 素材诊断与创作方向

## 核心判断

现有画面具备古装写实质感：粗麻、皮革、木门、尘土和自然光能建立可信世界。当前试片偏人物故事序章。要成为音乐宣传片，需要把“她经历了什么”压缩成“她为什么要开口、她此刻是什么态度”，并让红衣形象成为观众能记住的视觉落点。

建议木兰的创作命题为：**我替父出征，也要为自己留下名字。** 这是本项目的原创提案，不是用户已确定的歌词或片名。

## 两张人物图

| 现有材料 | 可以保留的价值 | 下一步 |
|---|---|---|
| 灰衣木兰：盘发、灰麻衣、深色腰束、布鞋、竹篓 | 日常感、家庭责任、克制情绪 | 作为出征前状态；建立干净的脸部、侧面、全身独立参考图 |
| 红衣木兰：高马尾、红发带、黑护甲、长剑 | 轮廓清楚，红黑搭配有识别度 | 作为宣传片主形象；先生成一个能看清脸的中近景测试 |
| 两张拼图都有脸、全身和材质细节 | 很适合人阅读、理解角色 | 拼图可作辅助设定；主参考尽量使用单人单视图，减少模型复制边框、文字或多人构图的风险 |

两个造型的发型和服装变化合理，但眼部妆感、皮肤、脸部比例在不同视图中有差异风险。先指定一张主脸，再做换装；不要把所有脸部格子都当作相等的身份标准。建议主脸先选灰衣图正面大头像，红衣负责服装和发型；如果你更喜欢红衣脸，可反向统一。

红衣图有伤痕细节。是否保留、位于哪侧，应在角色参考中明确；不能在镜头之间随机消失、换边。新角色设定也不需要照搬已有影视版木兰的标志性造型。

本轮按 0.5 秒抽帧检查，以下为近似视觉区间，不是逐帧确定的剪辑点。未进行听音和口型同步判断。

| 原片时间 | 已观察到的内容 | 制作建议 |
|---|---|---|
| 0–约 5 秒 | 月下门口中景，姿态变化较小 | 音乐广告开头可以只留约 1–2 秒，或改用红衣直视镜头开场 |
| 约 5–8.5 秒 | 全景、脸部、极近眼睛 | 有景别变化；眼睛特写中虹膜、皮肤风格需与主脸对照，避免过度放大产生偶像式精修观感 |
| 约 8.5–13 秒 | 清晨读信，镜头靠近脸部 | 是有效的剧情触发点；短版只保留“读到名字、表情改变”的最短动作 |
| 约 13–15.5 秒 | 信纸从手中落下，落到地面 | 可保留动作落点；纸上文字若承担剧情，改为后期可控文字或无需阅读的浅景深道具 |
| 约 15.5–19.5 秒 | 侧面木兰、看向屋内，过渡到父亲 | 可形成视线关系；跨时间光线变化需明确是回忆还是连续事件 |
| 约 19.5–22 秒 | 父亲与盔甲 | 是动机画面；宣传片可用 1–2 秒表达责任，无须完整铺陈 |
| 约 22–27.43 秒 | 返回月下木兰，逐渐拉远 | 与开头的视觉信息重复；可替换为穿甲、迈步、红衣定场 |
| 27.433–29.7 秒 | 黑屏 | 检测到约 2.267 秒尾部黑场；已制作去黑尾审片副本 |

原片硬字幕已经烧进画面，底部双语字在手机上可能偏小。以后保留无字母版，再统一加字幕；直接把现有横屏中心裁切成竖屏会损失人物、手部或文字，需逐镜重构构图。

已输出的“去黑尾审片版”只去掉尾黑并对末尾音频做 0.15 秒淡出，保留原有结构、横屏尺寸和硬字幕。这不是最终竖屏宣传片；音频结束位置仍需听音确认。

## 参考作品能学到什么

《500 Winters》的公开发布和报道，把古典人物的处境转成当代音乐中的心理表达。TapNow 官方发布称其完整制作流程在 TapTV 展示；这不等于作者在 GitHub 提供了开放许可证代码仓库。[发布页](https://www.bilibili.com/video/BV1ETPwzcEHg/)

《Six Ears》的作者说明围绕身份与内在冲突，并说明视觉使用可灵制作。该说明没有给出本轮可验证的具体模型版本或全套工程。[作者作品页](https://www.youtube.com/watch?v=cINNfhARgBQ)

据此，本项目可采用“古典人物的内心冲突 + 当代嘻哈态度 + 固定视觉符号”的创作方法。这里的镜头建议是为木兰设计的新方案，不冒充参考 MV 的逐镜结论。

木兰的重复符号建议只用三类：**红发带、征书、黑铁护甲**。月亮可作情绪背景。首支短片先建立一个世界，不急着同时加入霓虹城市、机甲、豪车和大战。

## 工作顺序

1. 确认歌曲与副歌，写出一句角色态度。
2. 固定主脸与两套服装，先通过红衣中近景测试。
3. 为每个镜头准备单独关键帧；一次先解决一个主要动作。
4. 每镜生成约 4–6 秒素材，再按歌剪成 1–4 秒；需要连续表演时才测试更长生成。
5. 剪辑先解决故事、节奏、身份，再做调色和字幕。
6. 用手机尺寸审片；记录成功与失败，把重复验证有效的方法写入 Skill。

一个 6 镜头 × 每镜 2 次 × 每次 5 秒的计划意味着尝试生成 60 秒素材。这是预算计算示例，不是成功率保证或平台价格。比较工具时看“每条可用镜头的实际成本”，不要只看单次便宜。
