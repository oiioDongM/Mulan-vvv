# Mulan vvv · 花木兰 AI 嘻哈视觉工作室

用户选定的项目名称：**Mulan vvv**。已核对仓库地址：[oiioDongM/Mulan-vvv](https://github.com/oiioDongM/Mulan-vvv)。本项目按创作者明确选择公开分享，包含初版制作教程、分镜、提示词、Skill 和辅助脚本。

目标：用即梦 Seedance 2.5 制作第一支 15–30 秒竖屏音乐宣传片，参考 Lil Wukong《500 Winters》《Six Ears》的创作方向，发展花木兰自己的身份与故事。

**当前推荐：先做 24 秒、9:16 的概念片。** 歌曲、歌词、BPM 和具体副歌段落尚未确认，分镜时间是工作假设。已有素材是两张人物设定拼图、一段约 29.73 秒试片。

## 从这里开始

1. 阅读 [素材诊断与创作方向](docs/01-素材诊断与创作方向.md)，先确认木兰要表达的态度。
2. 打开 [24 秒分镜与即梦提示词](docs/02-24秒分镜与即梦提示词.md)，先测试红衣木兰直视镜头的单个镜头。
3. 按 [GitHub 新手操作](docs/03-GitHub新手操作.md) 学习在本仓库查看文件、更新提示词和保存版本。
4. 每次生成后，用 [镜头记录](templates/shot-log.json) 保存提示词版本、实际费用、结果和淘汰原因。

## 怎么让 AI 使用这套 Skill

可以直接说：

> 使用 mulan-hiphop-video Skill。以花木兰为主角，先读取我的歌曲和人物参考图，做 24 秒竖屏音乐宣传片。输出分镜、每个镜头的即梦提示词、缺失素材和验收标准。标出哪些是已验证事实，哪些仍需测试。

项目中的 `skills/` 是便于 GitHub 网页上传的分发目录；它不会仅因上传 GitHub 就自动安装。安装方式见 GitHub 教程。Skill 不会改变视频模型权重，也不会自动获得账号权限。
